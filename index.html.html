미로 거리 지도

이동하지 않고 미로 전체의 구간 거리와 휴리스틱을 확인합니다.
출발과 도착은 서로 다른 막다른 길에 배치됩니다.
출발: 시작 위치 도착: 목적지 화살표 + 숫자: 방향별 실제 이동거리 ( 숫자 ): 도착까지의 휴리스틱 — 맨해튼 거리

실제 이동거리는 각 지점에서 다음 갈림길 또는 막다른 길까지의 셀 이동 횟수이며, 출발부터의 누적 거리가 아닙니다.
화살표는 해당 지점에서 처음 출발하는 방향입니다. 꺾인 통로도 실제 경로를 따라 계산합니다.
휴리스틱은 각 지점과 도착 사이의 행 차이와 열 차이를 더한 값입니다.
작은 셀에서 글씨가 작으면 셀 크기를 키우거나 아래 표를 확인하세요.

지점별 거리 표
좌표 (행, 열) 방향별 실제 이동거리 도착까지의 휴리스틱
